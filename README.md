# ClawdCrafter

A Minecraft mod that adds one block that turns a written prompt into a 3D build, generated by Claude.

- Type what you want and set the size of the area it may fill (X × Y × Z, 16 × 16 × 16 by default).
- Press **Preview** to see the build as see-through ghost blocks inside a red boundary.
- If you like it, press **Generate** to build it for real.

## Requirements

| | Version |
|---|---|
| Minecraft (Java Edition) | 26.3 |
| Fabric Loader | 0.19.5 or newer |
| Fabric API | 0.161.0+26.3 or newer |
| Java | 25 |
| Anthropic API key | from [console.anthropic.com](https://console.anthropic.com) |

The Anthropic Java SDK is bundled inside the mod jar (about 35 MB), so there is nothing else to install.

## Install

1. Install Fabric Loader and Fabric API for Minecraft 26.3.
2. Put `clawdcrafter-<version>.jar` in the `mods/` folder. For multiplayer, the server and every player need it.
3. Start the game (or server) once. This creates `config/clawdcrafter.json`.
4. Put your API key in that file (see below) and restart.

## Configuration: `config/clawdcrafter.json`

The **server** reads this file; in singleplayer that is your own game. The API key is never sent to players.

| Key | Default | Meaning |
|---|---|---|
| `apiKey` | `""` | Your Anthropic API key. If empty, the `ANTHROPIC_API_KEY` environment variable is used. |
| `model` | `claude-sonnet-5-5` | The Claude model to use. |
| `effort` | `medium` | `low`, `medium`, `high`, `xhigh` or `max`. Higher is slower and costs more, but builds are more detailed. |
| `maxDimension` | `64` | Largest size allowed in each size box (at most 128). |
| `blocksPerTick` | `1024` | How many blocks are placed per game tick (20 ticks = 1 second). Lower it if the server lags while building. |
| `opOnly` | `false` | Only server operators may use the block. Recommended on public servers, since every build costs API credit. |

## Usage

1. Take the **ClawdCrafter** block from the *Functional Blocks* creative tab, or craft it. The recipe is a placeholder: orange terracotta in the corners, black concrete on the sides, a diamond in the middle.
2. Place it and right-click it. A thin **red outline** shows the area the build may fill. It follows the size boxes and the direction you're facing.
3. Type a prompt, e.g. *"a cozy oak cabin with a stone chimney"*, adjust the sizes if you like, and press **Preview**.
4. After a short wait (usually tens of seconds), the build appears as **ghost blocks**:
   - Only you can see them, and nothing has been placed yet.
   - You can keep the screen open or close it and walk around.
   - When the preview is ready, these buttons appear:

| Button | What it does |
|---|---|
| **Generate** | Builds exactly the build you previewed. Claude isn't asked again. |
| **Clear** | Removes the ghost blocks. |
| **Retry** | Asks Claude again with the same prompt, for a different version. |

The build always appears **on the far side of the block, facing you**. It is centered on the block, and its floor is level with the block:

```
        [ build area X × Y × Z ]
                  ▲
             [ClawdCrafter]
                  ▲
                 you
```

Chat messages tell you when a preview is ready, when a build starts and finishes, and about any problems. Each block remembers its last prompt, sizes and build rule.

### Build rules

The **Build rule** button, to the right of Preview, decides what Generate does with blocks that are already in the build area. Click it to switch between the three rules. The current rule's description is shown under the button.

| Build rule | What Generate does |
|---|---|
| **Clear volume** (default) | Clears out all the blocks in the area, then builds. |
| **Replace blocks with build** | Builds the whole thing, including its open spaces such as rooms and doorways. Blocks outside the build are left alone. |
| **Build only where possible** | Places the build only where there is room. Air, grass, flowers, snow, liquids and torches count as room. Nothing else is replaced or removed. |

The rule is applied when you press Generate, so you can switch rules after previewing without asking Claude again.

![Build rule toggle](docs/screenshots/build-rule.png)

### What happens to things already in the build area

**Blocks are broken, not deleted.**
- Anything that gets removed or replaced drops what it would drop if you broke it by hand: seeds from grass, the torch itself, a chest and everything inside it.
- All of it, plus any items already lying in the area, is merged into stacks. They pop out **on top of the ClawdCrafter block** when the build finishes.
- Liquids are simply replaced.
- Bedrock, portals and other unbreakable blocks are never touched.

**Falling blocks:**
- Sand, gravel, anvils or concrete powder sitting on the top edge of the area are broken into items if the build would leave them hanging.
- Anything that still falls into the area is caught and turned into an item.

**Mobs, players, boats and minecarts** that would end up inside new blocks are lifted straight up to the first free space. For example, a cow standing where the floor goes ends up standing on the floor.

**Item frames and paintings** that lose the wall they hang on drop as items.

**Lag protection:** if clearing a huge area (for example 64³ of solid stone) would drop more than 256 stacks of loot, the most plentiful kinds are dropped last, and whatever goes past the limit is discarded. Items that were already items, such as chest contents, are never discarded. The chat message says how many stacks were discarded.

**Areas the mod won't touch:**
- Protected spawn areas and anything outside the world border.
- Areas that aren't loaded. Generate won't start until the whole area is loaded; it asks you to move closer. If part of the area unloads mid-build, the skipped blocks are reported.

**Who can build:** you must be within normal reach of the block, and able to build in your game mode, so not adventure or spectator.

## Limitations

- The crafting recipe is a placeholder.
- No undo, no in-game settings screen, and no support for land-claim or protection mods.
- Builds may use any block a survival player could get, including TNT, lava and fire. Use `opOnly` on public servers.
- You see one preview at a time, and only your own.
- Previews and unfinished builds aren't saved. After a server restart, press Preview again.
- If the server stops mid-build, the rest of the build isn't placed. Items collected so far are still dropped.
- No license has been chosen yet.
